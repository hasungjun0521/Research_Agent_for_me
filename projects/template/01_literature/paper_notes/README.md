# Paper Notes

Store one note per paper using `paper_note_template.md`.

Recommended filename format:

`firstauthor_year_shorttitle.md`

Each note should distinguish:

- What the paper actually claims.
- What evidence supports those claims.
- What assumptions or limitations matter for this project.
- Whether the paper suggests a baseline, metric, dataset, or critique.

Do not rely only on abstracts for key claims.

# Terminology

Use this file as the paper-wide glossary. Update it before drafting or revising
sections when a term, abbreviation, method name, dataset name, or metric label
could drift.

| Canonical Term | Allowed Variants | Definition | First Use / Section | Notes |
| --- | --- | --- | --- | --- |
| pending_project_terms | pending | Project terminology has not been finalized yet. | 06_writing/ | Replace with concrete method, dataset, metric, baseline, and abbreviation terms before drafting claims. |

## Rules

- Use one canonical term for each method, dataset, metric, baseline, and claim.
- Record abbreviations before using them in `06_writing/` or `09_report/paper/`.
- If a reviewer-facing term changes, update all working draft sections that use
  the old term.

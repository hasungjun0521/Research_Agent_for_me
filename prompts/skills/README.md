# Project Skills

Project skills are short reusable operating procedures for research agents. Load only the skills relevant to the current task; do not paste all skills into every pass.

Recommended default:

- Planning or routing: `context_budgeting.md`
- User/lab environment setup: `workspace_profile.md`
- Existing repo import: `research_repo_import.md`
- Privacy/publication audit: `privacy_publish_audit.md`
- Source/citation credibility: `source_credibility_audit.md`
- Experiment failure repair: `experiment_repair.md`
- Resource usage tracking: `resource_ledger.md`
- Mid-pass progress persistence: `progress_checkpoint.md`
- Dashboard-free state diagnosis: `state_doctor.md`
- Dashboard-free project status: `project_health.md`
- Rough idea intake: `brief_intake.md`
- Literature search rounds, paper notes, novelty checks: `literature_review.md`
- Smoke-first experiment DAG planning: `experiment_planning.md`
- Working claim/evidence graph: `claim_graph.md`
- Baseline repository structure comparison: `baseline_compare.md`
- Agent continuity quality audit: `agent_quality_audit.md`
- Autonomous skill creation from mistakes or corrections: `skill_synthesis.md`
- Experiment completion/result closeout: `experiment_completion.md`
- Research phase gates: `phase_gate.md`
- Replay/fork checkpoints: `run_checkpoint.md`
- Baseline work: `fast_baseline_intake.md`
- GPU experiment batching and dispatch: `gpu_parallel_execution.md`
- Multi-agent command batching and dispatch: `agent_orchestration.md`
- Any full experiment run: `experiment_smoke_first.md`
- Result evidence: `claim_and_result_evidence.md`
- Optional dashboard handoff when dashboard mode is explicitly enabled: `dashboard_refresh.md`
- Project handoff closeout: `project_closeout.md`
- Missing claim rows: `claim_table_backfill.md`
- Reviewer objections: `reviewer_risk_matrix.md`
- Stale command/vote state: `workflow_state_reconcile.md`
- Final-artifact folder cleanup: `report_hygiene.md`
- Project folder drift, 09_report bloat, lock debris: `project_hygiene.md`
- Writing or interpretation: `paper_claim_compression.md`
- Weekly progress slide deck: `weekly_deck.md`
- Final release: `artifact_packaging.md`
- Slow code or large analyses: `performance_measurement.md`

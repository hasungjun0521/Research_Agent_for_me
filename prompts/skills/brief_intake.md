# Brief Intake

Use when the research idea is rough and must become durable project state.

## When To Use

- A new project starts from a vague idea.
- Research question, motivation, contribution, dataset, metric, or baseline is missing.
- The user has answered some but not all setup questions.

## Agent Workflow

1. Capture only known fields.
2. Put unknowns in `state/open_questions.md` instead of guessing.
3. Update `00_brief/` and `02_planning/intake_summary.md`.
4. Route director triage after the brief has enough detail.
5. Save progress with the checkpoint hook if the pass is long.

## Outputs

- `00_brief/research_question.md`
- `00_brief/motivation.md`
- `00_brief/contribution_candidates.md`
- `00_brief/constraints.md`
- `02_planning/intake_summary.md`
- `state/open_questions.md`

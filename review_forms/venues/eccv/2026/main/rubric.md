# ECCV 2026 Main Review Rubric

## Recommendation Scale

| Score | Meaning |
| --- | --- |
| 6 | Accept |
| 5 | Weak Accept |
| 4 | Borderline Accept |
| 3 | Borderline Reject |
| 2 | Weak Reject |
| 1 | Reject |

## Confidence Scale

| Score | Meaning |
| --- | --- |
| 5 | Expert |
| 4 | High Confidence |
| 3 | Moderate Confidence |
| 2 | Low Confidence |
| 1 | Not Confident |

## Form Constraints

- Paper Summary: paragraph, 5 to 7 sentences, no bullets.
- Strengths: first-level bullets only if bullets are used, 2 to 3 items.
- Major Weaknesses: first-level bullets only if bullets are used, at least 3 items.
- Justification and rebuttal suggestions: balance strengths and weaknesses; request only realistic rebuttal clarifications, illustrations, or small experiments.
